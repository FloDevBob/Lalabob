# Crédits des sons du spectacle d'entraînement

Tous les sons viennent de [Freesound](https://freesound.org) et sont placés dans le domaine public par leurs auteurs
([CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)). Aucun crédit n'est obligatoire ; nous remercions
quand même leurs auteurs. Licence vérifiée sur la page de chaque son le **27/11/2026**, jour du téléchargement.

**Retouches communes** (script `sons/prepare_sons.py`) : rééchantillonnage en 48 kHz stéréo, niveau homogène
(ambiances −20 LUFS, bruitages −16 LUFS, crête vraie ≤ −1 dBTP : un son très dynamique reste un peu en dessous),
encodage AAC 256 kb/s (`.m4a`). **Boucles** : une coupe dont la fin se fond (2 s, puissance constante) dans le début,
pour un raccord sans clic ; les sons rythmés sont coupés sur un nombre entier de battements ou de tics.
